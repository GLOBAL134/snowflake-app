# SnowFlake — кроссплатформенная версия (Mac, Windows/Linux ПК, iOS, Android, Web)

Адаптированная версия **SnowFlake v2.4** с физикой сугробов, гирляндами на окнах, инструментами («Варежка», «Снеговик», «Лопата»), умным снегоуборщиком (трактор, ретро, снегоход, пингвин, своё фото с авто-удалением фона) и живыми обоями «Зимний домик».

---

## Готовые установщики (открыл — и установилось)

### Локальная сборка установщиков на Mac
- **macOS (`.pkg` авто-установщик в `/Applications` и `.dmg` образ)**:
  ```bash
  CSC_IDENTITY_AUTO_DISCOVERY=false npm run electron:build:mac
  ```
  Готовые файлы появятся в папке `release/`:
  - `SnowFlake-2.4.0-arm64.pkg` — двойной клик → «Продолжить» → «Установить», приложение само установится в `/Applications/SnowFlake.app`.
  - `SnowFlake-2.4.0-arm64.dmg` — классический образ диска.

### Автоматическая сборка установщиков для всех устройств (GitHub Actions)
В проекте настроен workflow [`.github/workflows/build-installers.yml`](.github/workflows/build-installers.yml). Достаточно запушить репозиторий на GitHub и запустить workflow (или создать тег `v2.4.0`), чтобы получить готовые файлы установки для всех платформ:
- **Windows ПК**: `SnowFlake Setup *.exe` (one-click NSIS-установщик — открываете файл, и он сам ставит приложение и запускает его)
- **macOS**: `SnowFlake-*.pkg` и `SnowFlake-*.dmg`
- **Linux**: `SnowFlake-*.AppImage` и `*.deb`
- **Android**: `app-debug.apk` (открываете `.apk` на телефоне — система сама устанавливает SnowFlake)
- **iOS**: `SnowFlake-unsigned.ipa` (устанавливается через AltStore / Sideloadly / Apple Configurator, либо через Xcode)

## Быстрый запуск из исходников

### 1. Веб / PWA (Mac, ПК, iPhone, Android — сразу без Xcode и Android Studio)
```bash
npm install
npm run dev
```
Откройте адрес из терминала в браузере на компьютере или с телефона в той же Wi-Fi сети (`--host` уже включён).
На iPhone (Safari → «Поделиться» → «На экран „Домой“») и Android (Chrome → «Установить приложение») можно установить как полноценное PWA-приложение.

### 2. Десктопный оверлей (macOS и Windows / Linux ПК)
Режим с прозрачным слоем поверх всех окон, иконкой в меню-баре / системном трее, отслеживанием открытых окон и Dock/панели задач:
```bash
npm run electron:start
```
Или в режиме разработки с горячей перезагрузкой:
```bash
npm run electron:dev
```
Сборка установочных пакетов:
- **macOS (`.dmg` / `.zip`)**: `npm run electron:build:mac`
- **Windows (`.exe` NSIS / Portable)**: `npm run electron:build:win`
- **Linux (`.AppImage`)**: `npm run electron:build:linux`

> **Примечание для npm v11+**: если при `npm install` на новой машине `electron` пропустил postinstall-скрипт, разрешите его или выполните `node node_modules/electron/install.js`.

### 3. Нативный запуск на iOS (Xcode) и Android (Android Studio)
Проекты `ios/` и `android/` уже созданы через Capacitor:
- **iOS** (нужен установленный Xcode на Mac):
  ```bash
  npm run cap:ios
  ```
- **Android** (нужен Android Studio / Android SDK):
  ```bash
  npm run cap:android
  ```
- При изменении веб-кода синхронизируйте сборку в нативные проекты:
  ```bash
  npm run cap:sync
  ```

## Особенности по платформам

- **macOS и Windows ПК (Electron)**:
  - Прозрачный click-through оверлей поверх всех окон и иконка снежинки в трее/меню-баре.
  - Отслеживание реальных окон (через `CGWindowListCopyWindowInfo` на macOS и `EnumWindows` / DWM на Windows), сугробы и качающиеся гирлянды на заголовках окон, сброс снега при резком перемещении окон.
  - **Варежка** работает даже при кликах по другим приложениям (через глобальный трекинг курсора).
  - **Живые обои (Зимний домик)** открываются фоновым окном позади остальных приложений, а также в меню трея доступен пункт **«Открыть окно-песочницу»**.
- **iOS, Android и браузеры**:
  - Полноэкранная WebGL2-сцена с живым зимним домиком и интерактивными перетаскиваемыми окнами-карточками (двигайте карточки, чтобы качать гирлянды, стряхивать снег или ставить на них снеговиков).
  - Свайп пальцем в режиме «Варежка» смахивает сугробы; в режиме «Снеговик» — скатывает и ставит снежные комы друг на друга.
  - Переключатель **«Ветер наклоном устройства»** в настройках позволяет управлять ветром наклоном смартфона.
